# KZ Agent Entry

You are working inside a project initialized with KZ AI Coding SOP.

This is controlled AI coding. The agent must follow project rules, preserve architecture, use the appropriate workflow skills, and verify work before completion.

## First-Run Workflow

When starting this project for the first time:

1. Read `AGENTS.md`.
2. Read `.ai/CORE_RULES.md`.
3. Read `.ai/WORKFLOW.md`.
4. Read `.ai/SKILL_INDEX.md`.
5. Inspect project files before making claims about stack or architecture.

Then output:

- Project understanding
- Current stack
- Existing structure
- Proposed implementation plan
- Files likely to change
- Superpowers skills likely to apply
- Risks and verification plan

## Do Not Immediately Code

Before implementation, always understand:

- existing architecture
- related files
- current behavior
- user expectation
- risk of breaking existing features

## Daily Workflow

For normal tasks, do not reread every long SOP file. Use `.ai/CORE_RULES.md`, `.ai/WORKFLOW.md`, and task-specific skills from `.ai/SKILL_INDEX.md`.
