# 精选 Skills

KZ SOP 内置少量补充 skills。它们会随包发布，但 `kz-sop init` 默认不会把长 skill 内容复制进业务项目。

执行：

```bash
kz-sop skills list
```

## 当前包含

| Skill | 使用场景 |
| --- | --- |
| `startup-pressure-test` | 拷问创业想法、真实问题、竞争、首批客户和 MVP 方向 |
| `grill-me` | 用一次一个问题的方式拷问方案或设计 |
| `karpathy-guidelines` | 写代码、审查代码或重构时，避免常见 LLM Coding 失误 |
| `spec-driven-development` | 写代码前先锁定一份小而可验证的规格与验收契约 |
| `waza-router` | 为 think、design、check、hunt、read、write、learn、health 选择 Waza 风格工作流 |
| `ecc-operator-system` | 审计多 Agent 工具链、指令面、安全门禁、记忆机制和验证流程 |
| `ralph-loop` | 跑自主的「干净上下文逐轮迭代」循环，或构建超过单个上下文窗口的功能 |
| `planning-with-files` | 把多步骤或研究型任务落盘，使其在上下文丢失、压缩或 `/clear` 后仍可恢复 |
