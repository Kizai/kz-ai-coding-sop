# KZ Core Rules

## Engineering Principles

1. Understand before editing.
2. Preserve existing features.
3. Prefer small and reviewable changes.
4. Do not introduce unnecessary dependencies.
5. Keep code readable, maintainable, and testable.
6. Do not hide errors.
7. Do not silently fail.
8. Explain assumptions when business logic is unclear.
9. Follow existing project architecture.
10. Every change must include verification steps.

## AI Behavior

- Do not guess missing context when files can be inspected.
- Do not rewrite large files unnecessarily.
- Do not delete existing code unless requested.
- Do not change public APIs without warning.
- Do not claim tests passed unless they were actually run.
- If Superpowers is available, use the relevant skill before acting.
- If Superpowers is unavailable, say so and follow `.ai/WORKFLOW.md`.
